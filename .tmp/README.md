# 运行时工作区

这里是本仓的本地运行时空间，完整约束以仓库根目录的 `AGENTS.md` 为准。

```text
.tmp/
├── runs/
│   └── <timestamp>-<name>/   # 一次用户工作的临时根目录
│       └── <skill-or-producer>/   # 按需组织
└── retained/
    └── <work-name>/   # 用户明确指定的长期本地工作目录
```

- `runs/<timestamp>-<name>/` 保存一次用户工作中可随任务结束清理的草稿、日志、中间结果和临时交付物，例如 `runs/20260903-163000-waic-report/`。
- 同一次工作调用多个 Skill、Loop、子 Agent 或插件时，共用同一 run root；其内可按产物生成者分目录，但不强制固定层级。
- `retained/<work-name>/` 仅用于用户明确指定的长期工作，不是 checkpoint 或跨任务状态的自动存放区，也不是正式仓库工作区。
- 默认工作写入 `runs/`；用户指定长期工作目录后，直接使用对应的 `retained/<work-name>/`，不要再为同一工作建立 run 或在两处复制内容。
- 两类工作目录内部都不规定统一层级或文件格式，由具体工作按需要组织。
- 不要在 `.tmp/` 根目录直接写入运行文件。
- 只有按照用户意图写入 `.tmp/` 之外的适当路径，结果才完成正式升格。
