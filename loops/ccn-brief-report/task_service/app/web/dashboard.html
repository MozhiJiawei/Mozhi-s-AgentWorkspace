API QUICKSTART

CCN 任务接口使用说明

以下命令可直接粘贴到 PowerShell 中运行。先配置地址和密钥，再按顺序执行五个典型接口。

REST · JSON · v1
使用前必须替换 API Key 占位符

将 <API_KEY> 替换为真正的密钥。不要把生产密钥提交到 Git、写入公开脚本、URL、截图或聊天记录。

00

准备地址与鉴权

所有接口和任务状态台都使用同一个 API Key。

$ApiBase = "https://ccn-api.haohaoxiaoyu.top"

# 必须替换成真实密钥；不要保留尖括号占位符
$ApiKey = "<API_KEY>"

$Headers = @{
    Authorization = "Bearer $ApiKey"
}
01

添加任务

POST

/api/v1/tasks

使用统一 API Key。建议每次请求提供唯一的 Idempotency-Key。

$TaskId = "TASK-$(Get-Date -Format 'yyyyMMddHHmmss')-$((New-Guid).ToString('N').Substring(0, 8))"
$CreateHeaders = $Headers.Clone()
$CreateHeaders["Idempotency-Key"] = "create-$TaskId"

$TaskBody = @{
    task_id    = $TaskId
    content    = "需要处理的任务正文"
    url        = "https://example.com/source"
    hotspot_id = "HS-001"
    period     = "2026-W32"
} | ConvertTo-Json

$CreatedTask = Invoke-RestMethod `
    -Method Post `
    -Uri "$ApiBase/api/v1/tasks" `
    -Headers $CreateHeaders `
    -ContentType "application/json; charset=utf-8" `
    -Body $TaskBody

$CreatedTask.data
02

按 ID 获取任务

GET

/api/v1/tasks/{task_id}

使用统一 API Key。返回任务正文、状态、时间及最近一次结果。

$Task = Invoke-RestMethod `
    -Method Get `
    -Uri "$ApiBase/api/v1/tasks/$TaskId" `
    -Headers $Headers

$Task.data
03

筛选任务

GET

/api/v1/tasks?status=...

支持 status、q、hotspot_id、period、limit 和 cursor。

$PendingTasks = Invoke-RestMethod `
    -Method Get `
    -Uri "$ApiBase/api/v1/tasks?status=pending&hotspot_id=HS-001&period=2026-W32&limit=50" `
    -Headers $Headers

$PendingTasks.data | Format-Table `
    row_number, task_id, status, hotspot_id, period

# 状态可选：pending、completed、failed
# q 可模糊匹配任务 ID、热点 ID 或周期
04

回传处理结果

POST

/api/v1/tasks/{task_id}/results

使用统一 API Key。结果采用追加模式，不覆盖历史记录。

$ResultHeaders = $Headers.Clone()
$ResultHeaders["Idempotency-Key"] = "result-$TaskId-attempt-1"

$ResultBody = @{
    outcome       = "completed"
    artifact_urls = @("https://github.com/MozhiJiawei/ccn-report/tree/main/开源软件分析/Example/20260805-example-source-understanding-codex")
} | ConvertTo-Json -Depth 5

$Result = Invoke-RestMethod `
    -Method Post `
    -Uri "$ApiBase/api/v1/tasks/$TaskId/results" `
    -Headers $ResultHeaders `
    -ContentType "application/json; charset=utf-8" `
    -Body $ResultBody

$Result.data
05

删除任务

DELETE

/api/v1/tasks/{task_id}

永久删除任务及其全部历史结果。重复删除保持成功，并通过 deleted 标记是否实际删除。

$DeletedTask = Invoke-RestMethod `
    -Method Delete `
    -Uri "$ApiBase/api/v1/tasks/$TaskId" `
    -Headers $Headers

$DeletedTask.data

批量删除：一次最多提交 200 个任务 ID，只计为一次写请求。

$BatchDeleteBody = @{
    task_ids = @($TaskId, "TASK-20260804-002")
} | ConvertTo-Json

$BatchDeleted = Invoke-RestMethod `
    -Method Delete `
    -Uri "$ApiBase/api/v1/tasks" `
    -Headers $Headers `
    -ContentType "application/json; charset=utf-8" `
    -Body $BatchDeleteBody

$BatchDeleted.data
REF

返回与错误约定

成功响应

{ "status": "success", "data": ... }

401

Key 缺失或无效。

409

任务 ID 或幂等键冲突。

422

请求字段或状态值不合法。

429

请求频率超过限制，请稍后重试。

!

确认删除任务

此操作不可撤销，任务的全部历史结果也会被删除。

SECURE ACCESS

连接任务状态台

请输入 API Key。密钥仅保存在当前浏览器标签页，关闭标签页后自动清除。
